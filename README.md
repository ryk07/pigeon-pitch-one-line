A [make.fun](https://make.fun/c/u-donrulezz-pigeon-pitch-one-line-af06c6cf) entry for
**Pigeon Pitch, One Line**: the one-line elevator pitch a city pigeon gives
investors for its startup.

## The pitch

> I'm the CEO of Crumb, the Airbnb for statues: I rent the head to tourists,
> the shoulders to first dates, and the plaque to the highest crumb-bidder.
> Now raising $2M. In actual seed.

## How it works

`main.py` (Python 3, standard library only) writes the pitch — one line,
181 characters — to `/output/entry.txt`. It reads nothing, uses no network,
and does not depend on the working directory.

Run it:

```sh
python3 main.py
```
